# Experiment log

Human-authored log of every training-batch launched on any host. One row per
**batch** (not per experiment) — the per-experiment logs live under
`results/logs/<study>.log`. This file exists to answer "what did we run,
when, and with which config" without having to spelunk through git history.

Not autogenerated. Every time a batch is launched, append a row here as
part of the launch checklist.

Sorted newest-first.

## Legend

- **Host**: `<user>@<hostname>`. GPU runs are on the lab machine, CPU
  smoke runs on the developer laptop.
- **Thesis commit at launch**: `git rev-parse --short HEAD` on the thesis
  repo at the time of launch.
- **`ibioml` submodule pin**: `git -C external/ibioml rev-parse --short HEAD`.
  Guarantees full reproducibility of the library state.
- **Preprocess config**: the config the pickles consumed were generated
  with. If the pickles were regenerated with `--force` before the batch,
  reference the resulting `data/processed/README.md` for the exact config.
- **Wall-time observed**: total from launch to last experiment done.
